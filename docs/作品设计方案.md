## 一、作品概述

**NeZha 任务管理**是一款「拍照成任务」的 AI 任务管理应用:用户拍摄课程表、值班表、通知单或手写清单,视觉大模型自动识别其中的任务、日期与时间,智能归一化后一键导入,并按设定自动安排闹钟与短信双通道提醒;任务数据通过匿名设备同步服务在云端持久化,换机不丢数据。

作品从**开发工具**(码道 CodeArts)到 **AI 推理**(ModelArts Studio/MaaS)、**存储**(RDS for MySQL)、**缓存**(DCS for Redis)、**部署**(ECS),全链路使用华为云产品,完整对应赛题一的各项硬性要求。

## 二、选题背景与痛点

| # | 痛点 | 现状 |
|---|---|---|
| 1 | 纸质/图片信息录入繁琐 | 课表、值班表、活动通知散落在微信群与照片里,手动录入清单 App 费时且易错 |
| 2 | 提醒方式单一 | 常见清单 App 只有一种提醒,开会、上课、打卡等场景容易漏看 |
| 3 | 跨设备同步有摩擦 | 换机/多设备使用时,传统同步方案多要求注册登录,门槛高 |
| 4 | AI 能力多为噱头 | 市面「AI 清单」多停留在对话生成,缺少对拍照识别、时间归一化等真实痛点的工程化打磨 |

**选题价值**:以真实高频场景(学生课表、职场通知)切入,把大模型视觉能力落到「识别 → 结构化 → 提醒 → 同步」的完整闭环,而非单点 Demo。

## 三、产品定位

- **一句话定位**:拍一张照片,任务自动排好、自动提醒、自动上云。
- **目标用户**:学生(课表/作业/活动)、办公人群(会议/值班/通知)、家庭(清单/缴费单)。
- **形态**:安卓移动应用(APK 可直接运行于安卓与鸿蒙 4.x 及以下系统;鸿蒙 NEXT 适配为后续规划),Expo 跨平台技术栈,可扩展 Web 演示版。

## 四、核心功能设计

### 4.1 每日任务
- 秒级实时时钟;左右滑动 / 箭头切换日期;
- 今日紧急任务(收藏)顶部提示条;右下角 FAB 快速新增;
- 任务按起始时间自动排序。

### 4.2 任务卡片与双通道提醒
- 任务要素:名称、备注、起止时间、闹钟提醒、短信提醒;
- 闹钟与短信**相互独立**的提前分钟数与铃声,适配不同场景(上课闹钟、会议短信);
- 说明:「短信提醒」为本地通知形式的短信式提示(应用内命名),不依赖运营商短信通道,离线可用;
- 编辑即重排提醒、删除即取消提醒,避免「幽灵通知」;
- Android 13+ 精确闹钟权限适配(SCHEDULE_EXACT_ALARM / alarmClock),保证按时送达。

### 4.3 日历
- 年 / 月滚轮选月,点选日期查看当日任务;
- 日期面板内直接新增与编辑,月历任务点着色(收藏加深描边)。

### 4.4 任务载入(核心 AI 链路)
1. **拍照 / 选图**:手机相册或现场拍摄课程表、通知单、手写清单;
2. **视觉大模型提取**:图片 + 可自定义提取模板 Prompt → 结构化任务条目;
3. **智能归一化**(工程重点):
   - 相对时间表达:「明天」「下午 3 点」「下周三」→ 绝对日期与 `HH:mm`;
   - 缺年份日期顺延:识别结果落在过去时自动顺延一年,与「星期 X」逻辑一致;
   - 缺时间自动跳过时间字段,不编造;
4. **自动导入 / 手动确认**:两种导入模式;确认模式下逐条勾选、字段可改;
5. **导入即规划提醒**:按预设自动为导入任务挂载闹钟 / 短信提醒。

### 4.5 多 AI 服务可切换
- 统一 OpenAI 兼容适配层,内置:**华为云 MaaS(主推)**、DeepSeek、通义千问 Qwen-VL、智谱 GLM-4V,以及本地 Mock(离线可完整演示流程);
- API Key 由用户本机填写、仅存本机,服务端零密钥。

### 4.6 云同步
- **匿名设备 ID**:首次启动自动生成,无需注册登录,零摩擦;
- **冲突策略**:全量状态 + 毫秒时间戳,服务端仅在「较新」时覆盖,离线设备回连不会用旧数据覆盖新数据;
- **离线优先**:本地持久化,断网静默降级为纯本地;恢复后自动按时间戳合并;
- **缓存加速**:读取先走 Redis 缓存,未命中回源 RDS。

## 五、技术架构

```
┌─────────────────────────────┐        ┌──────────────────────────────┐
│  NeZha App(Expo SDK 58)     │        │  华为云 ModelArts Studio     │
│  · 每日任务 / 日历 / 任务载入 │ 图片+  │  (MaaS 视觉大模型,昇腾推理)  │
│  · 本地通知(闹钟+短信)      │ Prompt│  OpenAI 兼容接口              │
│  · AsyncStorage 本地持久化   │──────▶│                              │
│  · AI 服务适配层(多供应商)   │◀──────│  结构化任务 JSON              │
└──────────────┬──────────────┘        └──────────────────────────────┘
               │ HTTP PUT/GET(匿名设备 ID + 时间戳)
               ▼
┌───────────────────────────────────────────────────────────────┐
│  华为云 ECS · Express 同步服务(server/)                        │
│  · /sync/:deviceId 全量状态上传 / 拉取                          │
│  · /health 健康检查(RDS + Redis 连通状态)                      │
└──────────┬───────────────────────────────┬────────────────────┘
           ▼ 读写                          ▼ 缓存(TTL 1h)
┌────────────────────────┐      ┌───────────────────────────────┐
│  华为云 RDS for MySQL   │      │  华为云 DCS for Redis          │
│  task_states:device_id │      │  sync:state:<deviceId>         │
│  + state JSON + 时间戳  │      │                                │
└────────────────────────┘      └───────────────────────────────┘
```

- 客户端:Expo SDK 58 / React Native 0.88 / expo-router / TypeScript strict,模块化架构(每日任务、日历、任务载入三模块互不依赖);
- 后端:Node.js + Express,CommonJS + 严格类型,`docker-compose` 本地一键联调(与华为云 RDS/DCS 同构);
- 开发工具:华为云码道 CodeArts 代码智能体(IDE 插件 / CLI),规范驱动开发。

## 六、华为云产品使用明细

| 华为云产品 | 用途 | 说明 |
|---|---|---|
| 码道 CodeArts 代码智能体 | 开发工具 | 代码生成、审查、调试与 Skills 执行,全流程留证 |
| ModelArts Studio(MaaS) | AI 视觉提取 | OpenAI 兼容接口调用视觉大模型(昇腾 NPU 推理),照片 → 结构化任务 |
| RDS for MySQL | 任务状态持久化 | `task_states` 表存设备全量任务状态(JSON 列 + 时间戳索引) |
| DCS for Redis | 同步读取缓存 | 热数据缓存 1h TTL,降低 RDS 读压力,加速多端拉取 |
| ECS 弹性云服务器 | 后端部署 | Express 同步服务,与 RDS/DCS 同 VPC 内网直连 |

## 七、创新点分析(对应创新性评分)

1. **「拍照成任务」端到端闭环**——市面上 AI 清单多止步于对话式生成,本作品打通「图像 → 大模型 → 结构化 → 提醒 → 云同步」全链路,并以手写、表格、通知单等多类真实图像为输入。
2. **中文时间表达的工程化归一化**——相对时间(明天/下周三/下午 3 点)、缺年份日期顺延、星期 X 锚定等细节规则,是真实可用性区别于 Demo 的关键工程积累。
3. **多 AI 供应商热切换与本地 Mock**——统一适配层让 AI 能力不锁定单一供应商,且无网络、无 Key 也能完整演示导入流程,适配答辩现场。
4. **无账号摩擦的匿名云同步**——设备 ID + 时间戳冲突策略 + 离线优先,以最低交互成本解决换机数据迁移,服务端拒绝旧数据覆盖。
5. **双通道独立提醒 + 精确闹钟适配**——闹钟与短信各自独立时间/铃声,并适配 Android 13+ 精确闹钟权限机制,提醒「到点必达」。
6. **全链路华为云**——开发(码道)、推理(MaaS)、存储(RDS)、缓存(DCS)、部署(ECS)五环节全部基于华为云,完整响应赛题要求。

## 八、完整性与工程规范

- 版本管理:Git,功能级提交,回退 tag 保护大改动;
- 质量门:每次交付必跑 `tsc --noEmit` + `expo lint` + `expo export --platform android`;
- 测试:E2E(Playwright)覆盖核心交互;后端接口联调实测(健康检查、往返、冲突、边界);
- 本地联调:`docker-compose` 起 MySQL + Redis,与华为云 RDS/DCS 同构,一键可复现;
- 部署:EAS 云端构建安卓安装包;后端 `npm run build` 产物直接部署 ECS。
